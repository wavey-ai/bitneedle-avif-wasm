# Retired

AVIF encoding now lives in
[`soundkit-avif`](https://github.com/wavey-ai/soundkit/tree/main/soundkit-avif),
inside the SoundKit repository.

The package is `@wavey-ai/soundkit-avif`. Its `/target` export provides
`createAvifEncoder`, including fixed-quantizer encoding, monochrome output
and target-byte fitting. The same package also provides AVIF decoding and
10-bit sRGB encoding.

Source, builds, tests and updates are maintained there. This repository is
archived for its history.
